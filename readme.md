## 📌 Overview

**Knowledge Vault** is a modern, ultra-premium landing page for a personal knowledge management (PKM) tool. It showcases a compelling value proposition: structured thinking over simple note‑taking. The page is designed to convert visitors into early‑access users through a clear narrative, elegant visuals, and frictionless calls‑to‑action.

This project was originally developed as an assignment for **[Programming Hero](https://programming-hero.com/)** (Assignment‑001) and later enhanced with additional SaaS‑style sections, a dark/light theme toggle, and full responsiveness.

---

## ✨ Key Features

- **🎨 Ultra‑Premium UI/UX** — Clean, modern design with gradient accents, glassmorphism, and smooth animations.
- **🌗 Dark / Light Theme** — Persisted via `localStorage`; toggle with one click.
- **📱 100% Responsive** — Seamlessly adapts to all devices from large desktops to small phones.
- **🧩 Complete SaaS Structure** — Includes Hero, Features, Notes (Problem), Second Brain, Experts, Categories, How It Works, Trust, Impact, Testimonials, Blog, Pricing, Admin, Contact, and a **single unified CTA**.
- **🚀 Performance Optimised** — Lightweight, no external frameworks, and minimal JavaScript.
- **♿ Accessibility Ready** — Semantic HTML, ARIA labels, and keyboard‑friendly interactions.
- **🔗 Smooth Scrolling** — In‑page navigation with offset for fixed navbar.
- **🎯 Conversion‑Focused** — Clear CTAs, social proof, and trust signals throughout.

---

## 🛠️ Tech Stack

- **HTML5** — Semantic markup for structure and SEO.
- **CSS3** — Custom properties, flexbox, grid, animations, and media queries.
- **JavaScript (Vanilla)** — Theme toggle, mobile menu, smooth scroll, and responsive behaviour.
- **Font Awesome 6** — Icon library for social icons, feature icons, and decorative elements.
- **Google Fonts (Inter)** — Primary typeface for clean, modern typography.

No CSS frameworks, no libraries — just handcrafted code.
